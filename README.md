# Musics-Backend-
A robust Node.js backend API featuring user authentication, role-based authorization, and media management. This system allows standard users and artists to register, log in, and log out securely. Role-based permissions restrict album creation capabilities exclusively to authenticated artists.

🚀 Key FeaturesDual
- Dual-Role Registration: Supports separate roles for standard Users and Artists.
- Secure Authentication: Implements JWT-based secure user login and logout mechanisms.
- Role-Based Authorization: Restricts the album creation endpoint strictly to verified Artists.
- Media Cloud Storage: Integrates ImageKit API for high-performance album artwork storage.
- API Testing Suite: Includes a pre-configured Postman collection for immediate endpoint testing.

🛠️ Tech Stack
- Runtime Environment: Node.js
- Backend Framework: Express.js
- Authentication: JSON Web Tokens (JWT) & bcryptFile
- Storage Cloud: ImageKit 
- Database: MongoDB
- Client Simulation: Postman

📋 Prerequisites 
Ensure you have the following installed on your local machine:
- Node.js
- npm
- registered ImageKit account
